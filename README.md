# TRACK
취업 준비 웹사이트

## 주요 기능
- 대시보드: 루틴 관리, 일정 캘린더, 스티커(할 일), 뉴스 스크랩 실시간 동기화
- 지원 현황: 기업별 지원 단계 관리, D-Day 트래킹, 검색/필터
- 자기소개서: 지원 현황별 자소서 문항 추가/수정/삭제
- 뉴스 스크랩: 기사 저장 및 관리
- 기업 공고 리스트: 검색 및 필터
- 시간 관리

## 업데이트 내역

### 2026-03-20
- **지원 현황 - 자기소개서 기능 추가**
  - 각 지원 카드에 펼치기(▼) 버튼 추가
  - 펼쳤을 때 자기소개서 문항 추가/수정/삭제 가능
  - 문항별 번호 표시, 글자 수 카운트
  - 문항 삭제 시 확인 팝업
  - 자소서 데이터는 로컬 스토리지에 저장

- **Sticker 중복 추가 버그 수정**
  - 할 일 추가 시 Enter + 버튼 클릭 중복으로 같은 항목이 여러 개 등록되는 문제 수정

- **로컬 개발 환경 개선**
  - vite.config.ts 불필요한 lovable-tagger 플러그인 제거
  - dashboardStore preloadData 8초 타임아웃 추가 (무한 로딩 방지)
