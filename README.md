# TRACK
취업 준비 웹사이트

## 주요 기능
- 대시보드: 루틴 관리, 일정 캘린더, 스티커(할 일), 뉴스 스크랩 실시간 동기화
- 지원 현황: 기업별 지원 단계 관리, D-Day 트래킹, 검색/필터
- 자기소개서: 지원 현황별 자소서 문항 추가/수정/삭제
- 뉴스 스크랩: 기사 저장 및 관리
- 기업 공고 리스트: 검색 및 필터
- 시간 관리

## 로컬 개발 서버 실행

```bash
cd frontend
npm run dev -- --port 8080
```
> 포트 8080 고정 필요 — Supabase 인증 리다이렉트 URL이 `http://localhost:8080`으로 등록되어 있어 다른 포트 사용 시 로그인 후 Vercel로 리다이렉트됨.
> 접속: http://localhost:8080
